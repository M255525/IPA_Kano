# IPA×Kano 滿意度分析

把問卷調查資料轉換成有科學依據的改善優先序，方法論為 **IPA（重要度—表現度矩陣）＋ Kano 品質屬性模型 ＋ 柏拉圖 80/20 分析**。這是 Claude 技能 `ipa-skill` 的散布包與交付物範例。

🔗 **線上使用**：<https://m255525.github.io/IPA_Kano/>

⚠️ **互動式儀表板需要授權序號才能使用**（見下方「授權序號」一節）。

## 這是什麼

- **互動式儀表板（單一 HTML，進階版）**：八個分頁——資料匯入 / 總覽洞察 / IPA 矩陣 / Kano 分析 / 整合優先序 / 柏拉圖 / 補充意見 / 匯出報告。全部運算預設於瀏覽器本機執行，資料不上傳；可重複上傳新批資料重算。
- **Claude 技能檔（`ipa-skill.skill`）**：打包好的技能，可在 Claude 設定 → Capabilities 上傳安裝，透過對話產生計畫書與儀表板交付物。
- **範例交付物**：一份相容 Word 的計畫書（.doc）範例，展示技能產出的另一種格式。

## 儀表板功能

- **三種輸入格式自動判斷**：IPA 寬表格、Kano 專用寬表格、長表格；判斷失敗時提供欄位對應介面
- **資料匯入管理**：可同時加入多個檔案／試算表連結，系統依題項名稱自動合併對齊；每個資料來源可手動標註「僅計入 IPA／僅計入 Kano／兩者皆計入」；一鍵清空所有資料重新開始
- **IPA 矩陣**：十字線位置（總平均／量表中點／自訂）與座標軸範圍皆可調整
- **Kano 分析**：M/O/A/I/R/Q 六屬性歸類、Better-Worse 滿意係數，象限圖座標軸範圍可調整（同 IPA）
- **柏拉圖 80/20 分析**、**自動洞察**、**選用 AI 智慧摘要**（自備 API 金鑰）
- **深色模式**、**專案存檔**（可存成 .json 下次載入繼續分析）
- **匯出報告**：下載 Word 報告 (.doc) 或列印／另存 PDF，皆附浮水印（透明度極低，不影響閱讀）
- **授權序號閘門**：整個工具需輸入有效序號才能使用，效期 12 個月，並持續顯示剩餘天數

## 怎麼用

1. 開啟 <https://m255525.github.io/IPA_Kano/>（會自動轉址到儀表板），輸入授權序號
2. 上傳問卷資料（.csv／.xlsx／.xls 或 Google 試算表連結），或先點「加入示範範例資料」快速體驗
3. 確認題項名稱對齊後按「套用並開始分析」
4. 依序查看「總覽洞察」「IPA 矩陣」「Kano 分析」「整合優先序」「柏拉圖」「補充意見」
5. 至「匯出報告」下載 Word 報告或另存 PDF

詳細操作說明見 [manual.html](https://m255525.github.io/IPA_Kano/manual.html)。

## 授權序號

本工具需先輸入授權序號並驗證通過，才能使用整個工具，效期自第一次驗證起算 12 個月。序號請向工具提供者索取。

## 技術架構

純前端單檔工具，**沒有任何建置流程、框架、npm 依賴**：

| 項目 | 做法 |
|---|---|
| 資料解析 | PapaParse（CSV）／SheetJS（Excel），全部在瀏覽器本機執行 |
| 圖表 | Chart.js |
| AI 智慧摘要（選用） | 瀏覽器直接 `fetch` 你選擇的 LLM 服務商官方 API（無後端代理），需自備金鑰 |
| 授權序號驗證 | Google Sheet + Google Apps Script（免費輕量後端），只做序號驗證，不經手問卷資料 |
| 頂部跑馬燈 | 與工作區其他工具共用同一個公告來源（可選、失敗不影響主功能） |

## 本機開發

不需要任何建置工具或安裝依賴，純靜態檔案：

```bash
git clone https://github.com/M255525/IPA_Kano.git
cd IPA_Kano
python -m http.server 8000
```

開啟 `http://localhost:8000/滿意度分析互動儀表板_進階版.html`（本機測試序號閘門需先部署自己的 Apps Script 後端，見 `SETUP-授權伺服器設定.md`）。
